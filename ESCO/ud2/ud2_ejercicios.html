Boletín de Ejercicios – UD02: Estructuras Condicionales en Python

1. Estructura condicional simple: if

Ejercicio 1

Comprueba si un número instroducido por el usuario es mayor que 0.

Ejercicio 2

Muestra un mensaje si una cadena introducida por el usuario no está vacía.

Ejercicio 3

Comprueba si una variable es None.

Ejercicio 4

Muestra un mensaje si un número introducido por el usuario está dentro del rango 1–100.

Ejercicio 5

Muestra un mensaje si un número introducido por el usuario es mayor que 0 y es par utilizando operadores lógicos.

2. Estructura condicional doble: if – else

Ejercicio 1

Determina si un número introducido por el usuario es positivo o negativo, mostrando el resultado al usuario.

Ejercicio 2

Comprueba si una persona es mayor de edad (pedir al usuario la edad), mostrando el resultado al usuario.

Ejercicio 3

Indica si una contraseña introducida por el usuario es correcta, mostrando el resultado al usuario.

Ejercicio 4

Comprueba si un número introducido por el usuario es par o impar, mostrando el resultado al usuario.

3. Estructura condicional múltiple: if – elif – else

Ejercicio 1

Clasifica una nota, sobre 10, introducida por el profesor como aprobada o suspensa.

Ejercicio 2

Clasifica una nota, sobre 10, introducida por el profesor en suspenso, aprobado o notable.

Ejercicio 3

Muestra el día de la semana según un número del 1 al 7 (teniendo en cuenta que la semana empieza el lunes). Si el usuario introduce un número entre el 1 y el 7, se le muestra el día. En caso de introducir otro número, se muestra "valor incorrecto".

Ejercicio 4

Clasifica una edad introducida por el usuario en varios rangos: bebé (hasta un año), niño (1-11), adolescente (12-17), adulto (18-67), anciano (más de 67).

4. Condicionales anidados

Ejercicio 1

Valida una nota sobre 10 introducida por el usuario. Es decir, si la nota es válida (está entre 0 y 10, incluidos) o no.

Ejercicio 2

Comprueba si un número introducido por el usuario es distinto de cero y positivo.

Ejercicio 3

Comprueba si una lista no está vacía y muestra si el primer elemento es igual a 1.

Ejercicio 4

Valida si una edad introducida por el usuario es un valor mayor o igual que cero, y muestra si está en edad de poder votar.

5. Operador ternario

Ejercicio 1

Determina si un número introducido por el usuario es positivo.

Ejercicio 2

Indica si la edad introducida por el usuario se corresponde con un mayor de edad.

Ejercicio 3

Determina si un número introducido por el usuario es par.

Ejercicio 4

Valida si una nota introducida por el usuario es válida, es decir, está entre 0 y 10, incluidos.

6. Estructura match – case

Ejercicio 1

Pedir un número al usuario e indicar con qué día de la semana se corresponde. En caso de introducir un valor que no se corresponda con los válidos se deberá indicar que es un valor no válido.

Ejercicio 2

Clasificar un número introducido por usuario como "cero", "negativo", "positivo". Utilizar match-case con condicionales.

Ejercicio 3

Crea un programa en Python que utilice la estructura match – case para analizar una lista de números enteros.

El programa debe:

  • Tener una lista llamada datos.
  • Comprobar si la lista contiene exactamente dos elementos.
  • Si la lista tiene dos elementos, mostrar por pantalla el mensaje: "Dos elementos".
  • Utiliza match para comparar la estructura de la lista, no su contenido concreto.

Ejercicio 4

Crea un programa que gestione la información de una persona utilizando un diccionario.

El programa debe:

  • Tener un diccionario llamado persona que contenga la clave "edad".
  • Utilizar la estructura match – case para analizar el diccionario.
  • Comprobar si la persona es mayor de edad (18 años o más).
  • Mostrar el mensaje "Mayor de edad" solo si se cumple esa condición.
  • Debes usar match junto con una condición adicional (if) dentro del case.

7. Mixto

Ejercicio 1

Escribe un programa en Python que haga lo siguiente:

  1. Pide al usuario que ingrese sus calificaciones en 3 asignaturas (por ejemplo, Matemáticas, Ciencias, Historia).
  2. Almacena estas calificaciones en un diccionario donde las claves son los nombres de las asignaturas y los valores son las calificaciones.
  3. Calcula la calificación promedio.

  4. Usa el operador ternario para proporcionar retroalimentación:

    • Si el promedio es 90 o más, imprime "¡Excelente trabajo!".
    • Si el promedio está entre 70 y 89, imprime "¡Buen trabajo!".
    • Si el promedio es menor a 70, imprime "Necesitas mejorar".

    • Usa anidamiento y el operador ternario para asignar una letra basada en el promedio:

    • Si el promedio es 90 o más, asigna 'A'.

    • Si el promedio está entre 80 y 89, asigna 'B'.
    • Si el promedio está entre 70 y 79, asigna 'C'.
    • Si el promedio es menor a 70, asigna 'D'.

Ejercicio 2

Escribe un programa en Python que haga lo siguiente:

  1. Inicializa un diccionario vacío para almacenar la lista de compras, donde las claves son categorías de artículos (por ejemplo, 'Frutas', 'Lácteos') y los valores son listas de artículos.
  2. Pide al usuario que ingrese una acción: 'agregar', 'eliminar' o 'ver'.

  3. Usa el operador ternario y anidamiento para manejar cada acción:

    • Si es 'agregar', pide la categoría y el artículo, luego agrega el artículo a la lista correspondiente en el diccionario.
    • Si es 'eliminar', pide la categoría y el artículo, luego elimina el artículo de la lista.
    • Si es 'ver', muestra toda la lista de compras.
    • Usa anidamiento para manejar las acciones sin bucles.
