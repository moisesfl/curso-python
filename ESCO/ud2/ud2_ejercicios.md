## 6\. Estructura `match – case`[](#6-estructura-match-case "Permanent link")

### Ejercicio 1 [](#ejercicio-1_5 "Permanent link")

### Ejercicio 2 [](#ejercicio-2_5 "Permanent link")

### Ejercicio 3 [](#ejercicio-3_5 "Permanent link")

Crea un programa en Python que utilice la estructura match – case para analizar una lista de números enteros.

El programa debe:

*   Tener una lista llamada datos.
*   Comprobar si la lista contiene exactamente dos elementos.
*   Si la lista tiene dos elementos, mostrar por pantalla el mensaje: "Dos elementos".
*   Utiliza match para comparar la estructura de la lista, no su contenido concreto.

### Ejercicio 4 [](#ejercicio-4_5 "Permanent link")

Crea un programa que gestione la información de una persona utilizando un diccionario.

El programa debe:

*   Tener un diccionario llamado persona que contenga la clave "edad".
*   Utilizar la estructura match – case para analizar el diccionario.
*   Comprobar si la persona es mayor de edad (18 años o más).
*   Mostrar el mensaje "Mayor de edad" solo si se cumple esa condición.
*   Debes usar match junto con una condición adicional (if) dentro del case.

## 7\. Mixto[](#7-mixto "Permanent link")

### Ejercicio 1 [](#ejercicio-1_6 "Permanent link")

Escribe un programa en Python que haga lo siguiente:

1.  Pide al usuario que ingrese sus calificaciones en 3 asignaturas (por ejemplo, Matemáticas, Ciencias, Historia).
2.  Almacena estas calificaciones en un diccionario donde las claves son los nombres de las asignaturas y los valores son las calificaciones.
3.  Calcula la calificación promedio.
4.  Usa el operador ternario para proporcionar retroalimentación:
    
    *   Si el promedio es 90 o más, imprime "¡Excelente trabajo!".
    *   Si el promedio está entre 70 y 89, imprime "¡Buen trabajo!".
    *   Si el promedio es menor a 70, imprime "Necesitas mejorar".
5.  Usa anidamiento y el operador ternario para asignar una letra basada en el promedio:
    
    *   Si el promedio es 90 o más, asigna 'A'.
    *   Si el promedio está entre 80 y 89, asigna 'B'.
    *   Si el promedio está entre 70 y 79, asigna 'C'.
    *   Si el promedio es menor a 70, asigna 'D'.

### Ejercicio 2 [](#ejercicio-2_6 "Permanent link")

Escribe un programa en Python que haga lo siguiente:

1.  Inicializa un diccionario vacío para almacenar la lista de compras, donde las claves son categorías de artículos (por ejemplo, 'Frutas', 'Lácteos') y los valores son listas de artículos.
2.  Pide al usuario que ingrese una acción: 'agregar', 'eliminar' o 'ver'.
3.  Usa el operador ternario y anidamiento para manejar cada acción:
    
    *   Si es 'agregar', pide la categoría y el artículo, luego agrega el artículo a la lista correspondiente en el diccionario.
    *   Si es 'eliminar', pide la categoría y el artículo, luego elimina el artículo de la lista.
    *   Si es 'ver', muestra toda la lista de compras.
4.  Usa anidamiento para manejar las acciones sin bucles.
